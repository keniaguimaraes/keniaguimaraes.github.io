📖 Introdução

Bolso em Dia é um sistema inteligente de rastreamento de despesas que utiliza inteligência artificial para categorizar automaticamente suas transações. O sistema aprende com o tempo, ajustando-se aos seus padrões de gasto.

✨ Principais Funcionalidades

  • Categorização Inteligente: IA aprende e sugere categorias automaticamente
  • Importação de Extratos: Suporta Nubank e C6
  • Rastreamento Detalhado: Visualize todas as suas transações
  • Filtros Avançados: Pesquise e filtre por múltiplos critérios
  • Edição em Massa: Altere várias transações de uma vez
  • Autenticação Segura: Login com Google OAuth2

🚀 Primeiros Passos

1. Acessar o Sistema

  • Acesse o sistema em seu navegador
  • Clique em "Continuar com Google"
  • Autorize o acesso com sua conta Google

2. Setup Inicial

Após o primeiro login, recomendamos:

Configurar Cartões de Crédito

  1. Vá para: Cartões de Crédito (menu lateral)
  2. Clique em Adicionar Novo Cartão
  3. Insira: Nome do cartão, Banco, Dígitos finais
  4. Salve

Criar Categorias Personalizadas

  1. Vá para: Categorias (menu lateral)
  2. Clique em Nova Categoria
  3. Dê um nome descritivo (ex: "Alimentação", "Transporte")

Importar Primeiro Extrato

  1. Vá para: Importar CSV (menu lateral)
  2. Selecione o banco: Nubank ou C6
  3. Faça upload do arquivo CSV exportado do seu banco

📥 Importação de Extratos

Bancos Suportados

✅ Suportados:
  • Nubank (Débito e Crédito)
  • C6 Bank (Débito e Crédito)

Como Importar

Passo 1: Exportar do Banco

Para Nubank:

  1. Abra o app do Nubank
  2. Vá para: Saques → Extrato
  3. Clique em ⋮ → Baixar Extrato (CSV)
  4. Escolha a data de início e fim

Para C6:

  1. Acesse o C6 Online
  2. Vá para: Extratos
  3. Clique em Baixar → CSV
  4. Escolha o período desejado

Passo 2: Importar no Sistema

  1. Menu → Importar CSV
  2. Selecione o banco: Nubank ou C6
  3. Clique em Selecionar Arquivo
  4. Escolha o arquivo .csv baixado
  5. Clique em Importar

Passo 3: Revisar Categorização

O sistema vai:

  • ✅ Carregar todas as transações
  • ✅ Categorizar automaticamente baseado no histórico
  • ✅ Mostrar um resumo de quantas foram categorizadas

🧠 Base de Treinamento

A "Base de Treinamento" é o cérebro do sistema. Ela armazena padrões que a IA aprendeu com suas correções.

O que é?

Um arquivo que mapeia descrições de transações → categorias corretas

Exemplo:

  • PADARIA CENTRAL → Alimentação
  • UBER CRISTIANO → Transporte
  • SHOPEE LTDA → Compras

Acessar a Base

  1. Menu → Treinamentos Cadastrados
  2. Você verá uma tabela colapsável com todos os padrões

Adicionar Padrão Manualmente

  1. Na tela de Treinamentos, vá até o final
  2. Preencha:
    • Descrição: O padrão a procurar (ex: "MERCADO")
    • Categoria: Qual categoria isso representa
  3. Clique em Criar

✅ Dicas da Base de Treinamento

  • Quanto mais padrões, mais inteligente o sistema fica
  • Use palavras-chave generalizadas (ex: "UBER" ao invés de "UBER SP")
  • Revise regularmente padrões com baixa confiança
  • A base é automática: cada correção adiciona um novo padrão

🔍 Pesquisa e Filtros

Pesquisa Rápida

  1. Em Rastrear Despesas, clique em 🔍 Pesquisa
  2. Digite uma palavra-chave (ex: "restaurante", "uber")
  3. A tabela atualiza em tempo real

Tipos de Pesquisa

  • Por descrição: "PADARIA" encontra "PADARIA CENTRAL"
  • Por valor: 15.90 encontra transações de R$ 15,90
  • Por categoria: "Alimentação" encontra todas daquele tipo

✏️ Edição em Massa

Altere várias transações de uma vez!

Como Funciona

  1. Em Rastrear Despesas, marque os checkboxes das transações:
    • Clique em ☑️ para cada transação
    • Ou clique em "Selecionar Tudo" no topo
  2. Você verá: X transações selecionadas
  3. Clique em Editar Selecionadas
  4. Uma modal aparece: Selecione a Categoria desejada
  5. Clique em Atualizar

Exemplo de Uso

Caso: Você importou um extrato e o sistema categorizou todas as compras da Amazon como "Compras" mas você quer "Diversos"

Solução:

  1. Pesquise por "AMAZON"
  2. Selecione todos os resultados
  3. Clique em "Editar Selecionadas"
  4. Selecione "Diversos"
  5. Clique em "Atualizar"

💡 Dicas e Boas Práticas

✅ Para Melhor Categorização

  1. Seja Consistente: Use nomes de categoria padronizados
  2. Corrija Rapidamente: Quanto antes corrige, mais o AI aprende
  3. Use Padrões Curtos: "PADARIA" é melhor que "PADARIA CENTRAL DO BAIRRO"
  4. Mantenha a Base Limpa: Revise a base de treinamento periodicamente

✅ Para Melhor Controle

  1. Importe Regularmente: Não deixe de importar extratos por muito tempo
  2. Revise Mensalmente: Faça uma revisão mensal das despesas
  3. Crie Subcategorias: Para gastos com muita variação
  4. Use Filtros: Filtre por categoria para análise

🔒 Segurança

  • Senhas: Use senhas fortes em suas contas de banco
  • Dados: Os dados ficam criptografados no servidor
  • Logout: Sempre faça logout ao sair
  • Compartilhamento: Cuidado ao compartilhar acesso com membros da família

🐛 Troubleshooting

❓ "Minhas transações não aparecem"

Solução:
  1. Certifique-se de que você importou um arquivo CSV válido
  2. Verifique se o banco está selecionado corretamente (Nubank vs C6)
  3. Tente importar novamente com um arquivo diferente

❓ "A categorização está muito errada"

Solução:
  1. Corrija manualmente algumas transações (pelo menos 10-15)
  2. Importe um novo extrato
  3. O sistema aprenderá com as correções

❓ "Não consigo editar em massa"

Solução:
  1. Certifique-se de estar marcando o checkbox corretamente
  2. Marque pelo menos 1 transação
  3. Clique no botão "Editar Selecionadas"

❓ "Os filtros não funcionam"

Solução:
  1. Clique em "Limpar Filtros" primeiro
  2. Depois aplique novo filtro
  3. Se ainda não funcionar, recarregue a página

❓ "Tenho um erro de login"

Solução:
  1. Limpe o cache do navegador (Cmd+Shift+Del no Windows)
  2. Tente fazer login novamente
  3. Se o erro persistir, entre em contato com suporte
